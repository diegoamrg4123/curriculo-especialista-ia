Pesquisa qualitativa · Controle humano

Synesis para Hermes Agent

Adaptação de uma skill para apoiar projetos Synesis: leitura de corpus, escrita da DSL, compilação, exportação e auditoria. O fluxo mantém as decisões metodológicas com o pesquisador e organiza aprovações de template, ontologia e itens piloto antes de anotações em lote.

Inclui referências por etapa, coordenação de subagentes e scripts de validação e testes de manutenção.

Ver skill Synesis no GitHub

Análise de dados · Estatística

AI Skill for R Stats

Desenvolvimento de instruções para agentes de IA voltadas à escrita, depuração e explicação de código R e estatística aplicada, com foco em análise exploratória, testes de hipótese, regressão, ANOVA e visualização.

Projetada para uso com diferentes modelos, com orientações sobre pressupostos estatísticos, valores ausentes e formatos brasileiros de dados.

Ver skill de R e estatística no GitHub

Integridade acadêmica · Verificação

ABNT Reference Verifier

Desenvolvimento de uma skill para orientar a verificação individual de referências bibliográficas em formato ABNT, buscando localizar as obras e identificar informações divergentes ou referências possivelmente inventadas por modelos de IA.

Organiza os resultados em relatório e encaminha casos inconclusivos à verificação humana, sem tratar ausência de resultados como prova de falsidade.

Ver verificador de referências no GitHub

Material educativo · IA responsável

Transcrição de entrevistas com IA: tutorial sobre o Buzz

Produção de vídeo educativo para pesquisadores, com demonstração de instalação e uso do Buzz para transcrição de entrevistas com modelos de IA executados localmente.

O tutorial aborda cuidados com dados sensíveis, a diferença entre processamento local e serviços em nuvem, a revisão e correção humana das transcrições e a documentação do software e do modelo utilizados na pesquisa.

Assistir ao tutorial no YouTube
